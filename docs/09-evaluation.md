# Évaluation et séparation des productions

## Modalité

Le module de 14 heures comporte une seule évaluation sommative : un QCM individuel contextualisé de 45 minutes, noté sur 20 et représentant 100 % de la note.

Les productions réalisées dans le repository restent formatives. Elles permettent de pratiquer la conception complète sans créer une seconde évaluation.

## Couverture recommandée

- besoin, invariants, MCD et cardinalités : 5 points ;
- MLD/MPD, types, clés, contraintes, index et normalisation : 5 points ;
- paradigmes document, clé-valeur, colonne et graphe : 4 points ;
- architecture polyglotte, source de vérité, synchronisation, gouvernance et migration : 6 points.

## Kit privé

Le repository étudiant n'inclut pas :

- les trois variantes équivalentes ;
- les réponses attendues ;
- la grille détaillée ;
- les distracteurs et leur justification ;
- les fichiers de génération du QCM ;
- les feuilles de correction.

Le QCM doit pouvoir être réalisé sur dossier numérique ou papier sans exiger l'exécution de Docker. Les règles de consultation des supports et d'usage des outils sont communiquées selon le règlement Ynov Campus.
