# Preuves

Ce dossier contient uniquement les sorties sélectionnées nécessaires pour vérifier une affirmation : extrait d'`EXPLAIN`, résultat de test, inventaire de volumétrie ou capture expurgée.

Les fichiers temporaires, volumes de bases, caches et exports complets ne sont pas versionnés. Chaque preuve renvoie vers la décision ou le document qu'elle soutient.
