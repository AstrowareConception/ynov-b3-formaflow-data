# Benchmarks

Un benchmark pédagogique éclaire une hypothèse ; il ne prétend pas établir un classement universel.

Chaque résultat doit référencer le protocole, le dataset, la version, la requête, les répétitions, les unités, le plan observé et les limites. Les résultats de postes différents ne sont comparés qu'après vérification des conditions d'exécution.
