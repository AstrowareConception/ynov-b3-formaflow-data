# Jeux de données

Ce dossier regroupera les jeux synthétiques déterministes utilisés par le module :

- `nominal/` pour le parcours principal FormaFlow ;
- `edge-cases/` pour les capacités, doublons, annulations, tarifs et paiements limites ;
- `flawed-schema/` pour les diagnostics de normalisation, contraintes et qualité ;
- `benchmark/` pour les comparaisons reproductibles.

Aucune donnée personnelle réelle n'est admise.
