# Zone NoSQL

Les propositions MongoDB, Redis, Cassandra et Neo4j sont séparées par profil. Chaque sous-dossier décrira le besoin, les accès, la structure, les duplications, les garanties, la rétention et le coût d'exploitation.

La présence d'un modèle n'implique pas que le moteur soit retenu dans l'architecture finale. Un seul profil est démarré à la fois.
