# Catalogue canonique

Ce dossier expose les éléments stables sous une forme exploitable par des scripts et par les autres repositories : acteurs, glossaire, règles métier, cycles d'état, parcours et traçabilité pédagogique.

Les identifiants publiés en 1.0.0 sont stables. Une correction de libellé peut être compatible ; la suppression ou le changement de sens d'un identifiant impose une version majeure du référentiel.
