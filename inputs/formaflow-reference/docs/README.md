## Ordre de lecture conseillé

Le lecteur découvre d'abord la vision, les acteurs et le glossaire. Les règles et cas limites fournissent ensuite la matière des exercices. La cartographie pédagogique, le contrat de transmission et la gouvernance concernent surtout le formateur et les mainteneurs des repositories.
