# Instantané du référentiel FormaFlow

Ce dossier recevra une copie figée des documents nécessaires provenant de `ynov-b3-formaflow-reference`.

La version initialement ciblée est `0.1.0`. Lors de l'implémentation, un manifeste indiquera le tag source exact, la date de copie et l'empreinte des fichiers.

Les étudiants consultent ces documents mais ne les modifient pas pendant le module. Toute hypothèse locale est consignée dans `docs/assumptions.md`.
