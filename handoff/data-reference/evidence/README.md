# Preuves sélectionnées

- `benchmark-result.json` : contexte, répétitions, égalité fonctionnelle et médianes du benchmark réel sur 10 000 lignes ;
- `before-index-plan.json` et `after-index-plan.json` : plans PostgreSQL JSON avec buffers ;
- `integrity-tests.md` : commandes et assertions qui démontrent capacité, unicité, historique et reporting.

Les temps ne constituent pas un objectif absolu. Les preuves utilisent uniquement des données synthétiques.
