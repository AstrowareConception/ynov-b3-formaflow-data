# Limites connues

- Le MPD prouve les trois invariants ciblés, pas toutes les politiques métier d'une marketplace.
- Taxe, remise, remboursement, multidevise, liste d'attente et report détaillé sont hors périmètre.
- Le benchmark porte sur 10 000 lignes dans Docker Desktop et ne généralise pas ses temps.
- La trace d'un million de consultations est préparée mais non exécutée.
- Cassandra est validé en mono-nœud ; aucune disponibilité distribuée n'est démontrée.
- Les projections MongoDB, Redis et Neo4j n'accordent aucun droit transactionnel.
- Aucun rendu SVG n'est fourni faute de moteur Mermaid local ; les sources `.mmd` sont présentes.
- Les durées légales de conservation et les objectifs de reprise doivent être décidés avec les parties compétentes.
- L'ownership reste hypothétique et aucun choix DDD ou applicatif n'est imposé.
