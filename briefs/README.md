# Briefs pédagogiques

Ce dossier recevra les briefs autonomes distribués séance par séance. Chaque brief indiquera l'état Git de départ, les objectifs, les contraintes, les fichiers attendus, les critères de réussite, le temps cible et la procédure de reprise.

Les briefs étudiants n'incluent ni solution, ni barème caché, ni élément d'un QCM sommatif.
